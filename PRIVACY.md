# WindowTrace privacy policy

Last updated: 18 November 2026

WindowTrace is a diagnostic tool made by Softviser Yazılım. It does not collect, store or transmit any
personal data.

## What the program reads

While it is running, WindowTrace reads the following from the computer it runs on and shows it in its own window:

- the title and class of windows that open and close,
- the name, command line, parent process and user account of the processes behind those windows and of
  processes that start.

## Where that information goes

Nowhere. It is kept in memory while the program is open and discarded when you close it.

- WindowTrace makes no network connections. There is no telemetry, no analytics, no crash reporting and no
  update check.
- It has no account, no advertising and no third-party components.
- It writes a file only when you choose Export, to the location you pick, and puts text on the clipboard
  only when you choose Copy. What you then do with that file or text is up to you. Command lines may
  contain sensitive values such as passwords; review them before sharing.

The one link in the program opens softviser.com.tr in your browser when you click it.
